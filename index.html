Projects

A few things built along the way.

  • ASL Translator with Mentra Glasses — an ASL translator using a vision-language model for Mentra Live smart glasses. View on GitHub ↗
  • Language Translator with Deepgram Voice AI — Atlas Lingua Demo is a turn-based interactive language tutor built with FastAPI, a lightweight browser frontend, Deepgram speech/language APIs, and OpenAI for tutor/translation generation. View on GitHub ↗
  • AI-Native Telehealth Platform — Breeze is an AI-native group therapy prototype for clinician-supervised telehealth groups where the AI is NOT a therapist. It is a clinician-supervised operational co-facilitator for group mechanics only: turn-taking, pacing, structured role-practice exercises, low-pressure participation prompts, and clinician-reviewable summaries. The licensed therapist remains the clinical lead and can override or stop AI support at any time. This is achieved by using a combination of deterministic hooks with tuned skills, Deepgram flux for STT/TTS capabilities. View on GitHub ↗
